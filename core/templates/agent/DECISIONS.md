# Decisions

One entry per durable decision. Format:

## <YYYY-MM-DD> — <short title>
- **Decision**: what was decided.
- **Reason**: why (the constraint that forced it).
- **Discarded alternatives**: what was evaluated and why not.
- **Consequences / REST**: what stays out, what needs revisiting.

---
## <YYYY-MM-DD> — example entry (delete it)
- **Decision**: use this format for every durable decision.
- **Reason**: the context stays reconstructible without re-reading the code.
- **Discarded alternatives**: none (example).
- **Consequences / REST**: none (example).
